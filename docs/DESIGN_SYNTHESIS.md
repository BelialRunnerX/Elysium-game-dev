# Elysium Design Synthesis — Owner Lock

**Updated:** 2026-09-07

## Pillars
| Source | Role |
|---|---|
| **No Man's Sky** | Galaxy scale, planet fantasy, ship travel |
| **Minecraft** | Voxel matter, building, mining tactility |
| **Dwarf Fortress** | **Critical** — deep fortress/civilization simulation (jobs, needs, history, institutions, medicine, military, justice, economy, threats). Depth must not be sacrificed for scope cosmetics. |
| **Factorio** | Factory/logistics inspiration — clear machines, belts, power, throughput, local production graphs |
| **Diablo** | Authored combat, loot, character fantasy |

## Non-negotiables
1. DF-grade system depth remains a project requirement for the full game; Alpha vertical slice may stage delivery but must not redefine the game as shallow survival-only.
2. Factorio informs industry UX and logistics clarity; industry stays emit-only for Suspicion and respects Architecture network locality.
3. Presentation (CONCEPT v0.7) expresses solarpunk + anime-influenced characters without deleting simulation complexity.
